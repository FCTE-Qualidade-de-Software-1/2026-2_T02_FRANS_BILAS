# Qualidade de Software 1 (FGA0315) — Turma 01 (2026.2)
## Equipe Frans Bilas — Avaliação do Brasil Participativo

Repositório da disciplina de **Qualidade de Software 1** da Universidade de Brasília (Campus UnB Gama: Faculdade de Ciências e Tecnologias em Engenharia - Brasília — FCTE), ministrada pela Profa. Dra. Cristiane Soares Ramos.

O objetivo do projeto é a avaliação da qualidade de produto de software da plataforma [Brasil Participativo](https://gitlab.com/lappis-unb/decidimbr/decidim-govbr) (baseada no ecossistema Decidim), orientada pela norma **ISO/IEC 25010:2023 (SQuaRE)**, com definição e desdobramento de métricas via **GQM (Goal-Question-Metric)** e acompanhamento de processo via **PSM/CID**.

### Características de Qualidade Avaliadas

Conforme aprovado e alinhado ao escopo da disciplina:

1. **Capacidade de Interação** *(Interaction Capability — antiga Usabilidade na ISO/IEC 25010:2023)*
2. **Manutenibilidade** *(Maintainability)*
3. **Segurança** *(Security)*

### Estrutura do Repositório

- `documentation/`: Documentação e GitPage estática mantida com [Zensical](https://github.com/krzysztofzuraw/zensical).
  - `documentation/content/index.md`: Página inicial da GitPage.
  - `documentation/content/article/source/main.tex`: Artigo científico em LaTeX.
  - `documentation/content/entregas/1.md`: Apresentação / slides da Entrega 1.
- `.agents/skills/writing/SKILL.md`: Skill `humanizer` para refinamento rigoroso de escrita humana contra vícios de IA.
- `references/`: Materiais de apoio, notas de aula e plano de trabalho (ignorado pelo Git).

### Configuração do Ambiente e Hooks

Para ativar os hooks locais do Git e garantir a validação da escrita humana antes de cada commit:

```bash
git config core.hooksPath .githooks
```

Consulte o [CONTRIBUTING.md](CONTRIBUTING.md) para detalhes sobre o fluxo de branches, convenções de commits e diretrizes anti-meat-proxy.
